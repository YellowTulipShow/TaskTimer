# 替代 Window 自带的任务计划程序

我想用WPF做一个定时触发任务的小程序 (类似于window自带的任务计划程序, 但是这个不一定会好用, bug非常多)
如果再GitHub能找到相同功能的也可以推荐
要求: 尽量使用最简洁的代码实现
功能要求:
1. 核心功能: 指定一个脚本或程序路径, 根据页面上用户指定的规则定期/定时进行执行
2. 要求在后台运行程序每分钟执行一次, 前台界面管理多个程序/脚本的路径/触发的时间点(月/周/日/时/分)
3. 增加系统管理:
	1. 是否开机自启动
	2. 默认开启关闭前台界面
	3. 如QQ那样进入后天运行时关闭前台界面再任务栏右下角右键图标有退出/管理单一程序的监控终止/打开前台页面
